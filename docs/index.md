# Elastic MDS

Elastic MDS is MetaFluent's elastic Market Data System: an enterprise-class platform for
distributing real-time and non-real-time content to scalable applications through the
industry-standard APIs you already know - **JMS, JDBC, and SQL**. If you know those,
you already know how to use Elastic MDS.

Elastic MDS is built on the **StreamLens** integration framework.
